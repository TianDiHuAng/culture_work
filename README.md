# 中外文学名著导读库

一个纯静态的文学名著导读站点：每部作品一篇导读（固定 8 节结构），每位作家一篇小传，每部作品一幅原创 SVG 图（人物关系图 / 主题结构图），另有可筛选的作品总览、作家索引与文学史时间线。**无任何外部依赖，克隆后直接用浏览器打开 `site/index.html` 即可离线浏览。**

> 当前版本：v1（60 部作品，中外各 30）· v2 扩充进行中（持续新增作品页）

## 收录一览（v1）

- **作品 60 部**：中国 30（先秦诸子与诗集 → 明清小说 → 现当代）· 外国 30（古希腊史诗 → 20 世纪）
- **作家 55 位**：屈原、司马迁、曹雪芹、鲁迅、沈从文、刘慈欣……荷马、但丁、莎士比亚、托尔斯泰、卡夫卡、马尔克斯……
- **来源 100 条**（99 条 verified）：以 Encyclopaedia Britannica 为主，辅以英文维基百科、央视网、求是、人民网、中国作家网、中国新闻网、书格古籍库等，全部经实际打开核对
- **体裁分布**：小说 34 · 诗歌 8 · 戏剧 8 · 故事集 6 · 散文 4

## 每部作品的固定结构

1. 基本信息（书名、原名、作者、成书/出版年、体裁、语言——均标注来源）
2. 创作背景
3. 内容脉络（点到"读者需要的程度"，不逐章复述）
4. 主要人物表
5. 主题与艺术特点
6. 影响与评论（**每条注明出处**，争议话题列各方说法）
7. 阅读建议（难点、推荐版本、入门顺序）
8. 待核实（查不到的如实标注，不编造）

## 目录结构

```
├── data/
│   ├── works/     # 60 部作品的 JSON（内容源）
│   └── authors/   # 55 位作家的 JSON
├── sources.json   # 来源库（id / 标题 / 链接 / 类型 / verified）
├── tools/
│   ├── build.py   # JSON -> site/ 静态站点
│   ├── check.py   # 全库校验（必填字段/日期/来源/去重/内链/SVG 出界）
│   └── svggen.py  # SVG 生成器（内置防出界）
├── site/          # 生成的静态站点（可直接打开）
└── works_list.md / DECISIONS.md / BLOCKERS.md / REPORT.md / PROGRESS.md
```

## 构建与校验

```bash
# 重建站点（data/*.json + sources.json -> site/）
python tools/build.py

# 全库校验（必填字段、日期合法、事实带来源、无重复、内部链接、SVG 不出界）
python tools/check.py
```

- Python 3.11+，仅标准库，无任何第三方依赖。
- 校验不通过则退出码为 1；`site/` 由构建生成、可随意删除重建。

## 内容原则

- **不编造**：出版年份、人名、情节、引文均以已核来源为锚；查不到的进入各页"待核实"。
- **引文克制**：仅引用公有领域原文并限量；现代译本受版权保护，只列书目不作搬用。
- **评价署名**：观点写明是谁的评价（撰稿人/评论家/机构）；有争议的列出各方说法。
- **诚实边界**：约数百条待核实事项明确标出，等待后续版本补证。
